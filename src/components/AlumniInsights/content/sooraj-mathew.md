# COMMVAULT PLACEMENT EXPERIENCE (CYBERSECURITY-BASED)

## OVERVIEW

Commvault’s recruitment process focuses on Cybersecurity, Software Development, and Software Testing.

There are two main profiles offered:

* Software Development Engineer (SDE)
* Software Development Engineer in Test (SDET)

The overall process evaluates candidates based on problem-solving ability, conceptual understanding, and hands-on application — particularly in Operating Systems, Networking, and Secure Systems.

---

## ROUND 1: ONLINE ASSESSMENT

### Tracks and Languages

* SDE – Java / C++
* SDET – Python

### SDE TRACK

**Sections:**

1. 3 Coding Questions
2. 1 Language-Specific MCQ Section (based on chosen language: Java or C++)

**Focus Areas:**

* Core programming and logic building
* Multithreading and concurrency
* Object-Oriented Principles
* Language-specific concepts

### SDET TRACK

**Sections (4 Total):**

1. Coding Questions (Python-based)
2. Python Language Section
3. Networking MCQs
4. Operating Systems MCQs

**Focus Areas:**

* Python fundamentals and automation
* Networking protocols and OSI layers
* OS concepts like processes, threads, and scheduling

**Evaluation:**

Candidates who passed all test cases in at least one coding question were given higher preference for the next round.

**Preparation Tips:**

* SDE – Strengthen Java/C++ concepts, OOP, and multithreading.
* SDET – Focus on Python, OS, and Networking fundamentals.

## ROUND 2: TECHNICAL EVALUATION (ON-SITE AT RAJAGIRI)

(All Kerala-selected candidates from around five colleges participated in this round.)

### SDE TRACK

**Format:**

* Long coding round (~5–6 hours) conducted under Commvault mentor supervision.

**Task:**

* Implement core Git functionalities such as commit, branch, push, and pull in the selected language (Java/C++).

**Focus:**

* Logical implementation and design
* System-level understanding
* Efficient and modular code

### SDET TRACK

This round consisted of three main parts focusing on Testing, API Implementation, and Python Coding.

#### 1. Website Bug Identification

* A web application was provided for testing.
* Candidates had to identify bugs and prepare a detailed Bug Report.

**Reporting Tip:**

Prepare the bug report in the following structured format:

* Bug Name – Short descriptive title
* Bug Type – UI / Functional / Security / Performance
* Severity – Low / Medium / High / Critical
* Description – Clear explanation, steps to reproduce, expected vs. actual result

#### 2. API Implementation

* Task: Write code using Google Drive APIs (e.g., upload and manage files).
* Focus: Correct API usage, logical flow, and understanding documentation.
* Mentors were available for clarification and guidance.

#### 3. Python Coding Section

* A couple of Python questions were provided.
* Candidates wrote and tested their own code; evaluation was done later.
* Focus on file handling, multithreading, and writing clean modular code.
