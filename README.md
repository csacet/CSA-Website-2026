A responsive landing page for the Computer Science Association at CET.

## Tech Stack
- **Framework:** React 18
- **Build Tool:** Vite
- **Styling:** Vanilla CSS
- **Deployment:** Vercel

## Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
